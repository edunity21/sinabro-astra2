# 시나브로 · Astra Editorial Edition

Claude 원본의 9개 메뉴, 모든 콘텐츠와 기능을 유지하면서 사진 표지와 특집 지면으로 다시 디자인한 버전입니다.

## 먼저 보기

압축을 완전히 풀고 index.html을 Edge 또는 Chrome에서 여세요. 보고서 전문은 report.html입니다.

## 달라진 디자인

- SINABRO 마스트헤드와 실제 공연 사진을 결합한 잡지 표지
- 네 글자를 클릭하는 원본 탐색 기능을 표지 위에 유지
- 각 과제 도입부를 제목·질문·수업 사진이 나란히 놓이는 특집 지면으로 구성
- 큰 번호의 활동 카드, 검은 4단 수업 절차, 사진이 붙은 플랫폼 자료 카드
- 성과·기록·자료실에 각기 다른 영문 지면 제목 적용
- 원본 사진 전체와 보고서 전문, 부록 유지
- 홈 메뉴의 밝은 사각형 없이 얇은 밑줄로 현재 위치 표시

## GitHub 업로드

1. 저장소에 이 폴더 안의 파일과 img 폴더를 모두 업로드합니다. ZIP 자체를 올리는 것이 아닙니다.
2. 저장소 맨 위에 index.html이 보여야 합니다.
3. Settings → Pages에서 Deploy from a branch, main, /(root)를 선택하고 Save합니다.
4. 배포 후 Pages 화면에 표시된 주소로 접속합니다.

별도 빌드는 필요하지 않습니다. 기존 버전과 비교하려면 새 저장소를 사용하세요. 실제 업로드는 이번 작업에 포함하지 않았습니다.

## 수정할 파일

- editorial.css: 사진 표지와 편집 레이아웃을 포함한 이번 디자인
- astra-webzine.css: 공통 글꼴·색상·컨트롤 기본 스타일
- index.html: 원본 전체 플랫폼과 새 표지·챕터 사진 요소
- report.html: 보고서 전문과 새 표지
- img/: 원본 이미지 243개

본문과 기능 스크립트는 원본 자료를 기반으로 유지했습니다. 원본 통계나 문안의 재분석·개정은 이번 디자인 작업에 포함하지 않았습니다.
기존 외부 영상·플랫폼·Google 웹폰트는 인터넷 연결이 필요합니다. 연결되지 않으면 시스템 대체 글꼴로 표시됩니다.
